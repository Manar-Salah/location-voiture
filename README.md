
# Projet Location Voiture

Projet web PHP / MySQL / JavaScript pour la gestion d'une agence de location de voiture.

## Technologies
- HTML5
- CSS3
- JavaScript
- PHP 8
- MySQL

## Installation
1. Copier le dossier dans htdocs (XAMPP)
2. Importer database/location_voiture.sql dans phpMyAdmin
3. Configurer config/database.php
4. Lancer Apache et MySQL
5. Ouvrir http://localhost/location_voiture_project

## Fonctionnalités
- Catalogue véhicules
- Réservation
- Gestion clients
- Dashboard admin
- Validation JS
